    - Imports: `import type { Verb, Tense, Subject } from "../dataset/types";`,
      `import { SUBJECTS } from "../dataset/types";`, `import { verbs } from "../dataset/verbs";`,
      `import { shuffle } from "./random";`, type imports + value import for InsufficientVerbsError
      from "./types". Use the import type vs value split.
    - `generate(options: GenerateOptions, random: () => number = Math.random): QuizSession` —
      ONLY this function defaults random. Filter eligible verbs
      (`verbs.filter(v => options.includeIrregular || !v.isIrregular)`), build the flat pool via
      `flatMap` over eligibleVerbs × options.tenses × SUBJECTS producing Triple objects, call
      `sampleTriples(pool, 10, random)`, then map each triple through `buildQuestion(triple, eligibleVerbs, random)`.
    - `export function sampleTriples(pool, count, random)` — mandatory random; throws
      `new InsufficientVerbsError(pool.length, count)` when `pool.length < count`; otherwise
      `shuffle(pool, random).slice(0, count)`. The pool is unique by construction (cross product
      has no duplicate triples) so shuffle-then-take needs no extra Set check.
    - `export function buildQuestion(triple, allVerbs, random): Question` — look up the verb in
      allVerbs, `correctAnswer = verb.conjugations[triple.tense][triple.subject]`, call
      pickDistractors, then `choices = shuffle([correctAnswer, ...distractors], random)`.
    - `export function pickDistractors(verb, tense, subject, allVerbs, random): string[]` —
      same-verb pool = other 5 subjects' forms for this tense, deduped via Set, excluding the
      correct answer, shuffled; take up to 3; if fewer than 3, backfill from other verbs'
      `conjugations[tense][subject]` forms, deduped against an exclude Set of {correct, chosen},
      until exactly 3. Return exactly 3.
