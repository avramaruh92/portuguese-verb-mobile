## Spacing Scale

Declared values (existing project scale, `src/theme/tokens.ts` — multiples of 4, `sm`/`md`/`lg` used at 8/16/24, `choiceGap` at 12 is a pre-existing named exception unrelated to this phase):

| Token | Value | Usage |
|-------|-------|-------|
| sm | 8px | Compact element spacing |
| md | 16px | Screen horizontal padding (`styles.container`) |
| lg | 24px | Section spacing (replaces `heading`'s `marginBottom: spacing.lg` below the lockup) |
| xl2 | 48px | Major section breaks (not used by this phase) |
| xl3 | 64px | Page-level spacing (not used by this phase) |

Exceptions: none for this phase. The lockup `Image` container reuses `spacing.lg` as its `marginBottom`, matching the `Text` it replaces (`app/index.tsx` line 179, `styles.heading.marginBottom`) so the vertical rhythm of the Setup screen is unchanged.

## Typography

Not applicable in the traditional sense — the wordmark ("lafa") and tagline ("Learn it. Say it.") are rendered as vector text baked into the PNG at generation time (candidate SVG: wordmark at `font-size="220"`/`font-weight="800"`, tagline at `font-size="54"`/`font-weight="600"`, both within a 1600×520 viewBox), not as live RN `Text` components. No new `typography` token is introduced. The existing `typography.heading` token (`fontSize: 20, fontWeight: 600`) that `styles.heading` used is retired for this element only — it is not reused elsewhere on the screen, so no other screen is affected.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| (retired) heading — was `<Text>Lafa</Text>` | 20px | 600 | default | — replaced entirely by the `Image` lockup; no live-text equivalent remains for this element |

## Color

No new colors are introduced. The candidate lockup's palette already matches production tokens exactly (confirmed in `32-CONTEXT.md` canonical refs):

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFF9F6` (`colors.background`) | Lockup background rect (`rx="64"`), matches screen `styles.container.backgroundColor` — the lockup's rounded-rect background should read as blended into the screen, not a distinct card |
| Secondary (30%) | `#F2643E` (`colors.primary`) | Mark fill + wordmark "lafa" text fill |
| Accent (10%) | `#1F7F66` (`colors.success`) | Single green dot only (`<circle r="25">`) — the lockup's sole accent mark |
| Destructive | `#D64545` (`colors.error`) | Not used in this asset (no destructive action on this element) |

Accent reserved for: the single green dot in the lockup graphic only. Do not introduce `colors.success` anywhere else on the Setup screen as a result of this phase.

Text/tagline color: `#24201E` (`colors.text`) for the "Learn it. Say it." tagline — matches body text color used everywhere else on screen.

## Visual & Layout Contract (phase-specific — image lockup rendering)

| Property | Value | Rationale |
|----------|-------|-----------|
| Source SVG (promoted) | `assets/brand/lafa-homepage-lockup.svg` | Promoted from `assets/brand/candidates/lafa-homepage-lockup.svg`, mark updated to the 3-layer canonical mark (`mark-depth`/`mark-fill`/`mark-highlight`) per CONTEXT.md D-01/D-02 |
| Source SVG viewBox | `0 0 1600 520` (aspect ratio 40:13, ≈3.077:1) | Unchanged from candidate — no cropping/trimming per D-04 |
| Generated PNG | `assets/images/lafa-homepage-lockup.png` | Produced by `scripts/generate-brand-assets.ts`'s new render step, reusing `extractMarkOnly()`/`composeMark()` |
| PNG render scale | 2x-3x expected display size (e.g. rendering at ~2400-4800px width if displayed around ~800-1200px wide on screen) | Follows the established `icon.png`/`splash-icon.png` "render much larger than display size" pattern (CONTEXT.md D-03); exact factor left to generator implementation, must stay crisp on 3x-density devices |
| Density variants | None — single PNG only | Explicitly rejected `@1x`/`@2x`/`@3x` convention (D-03); this codebase has no precedent for density-variant filenames |
| In-app `Image` sizing | Explicit `width`/`height` (or `aspectRatio: 1600/520` with a fixed `width: "100%"` and computed `height`) set in `StyleSheet.create`, NOT flex-only sizing | RN `Image` requires explicit dimensions or `aspectRatio` to avoid a 0-height collapse; matches "fixed-aspect-ratio Image with explicit width/height style" per D-03 |
| `resizeMode` | `"contain"` | Preserves the lockup's full composition (mark + wordmark + dot + tagline) without cropping at any screen width; matches D-04's "no cropping" requirement |
| Horizontal placement | Centered within `styles.container`'s existing horizontal padding (`spacing.md`), same as the retired `Text` (`textAlign: "center"`) | Keeps Setup screen's centered visual rhythm unchanged |
| Vertical placement | Replaces `<Text style={styles.heading}>Lafa</Text>` in-place at `app/index.tsx` line 74, as the first element after `<OfflinePill />` | No reordering of screen structure |
| Max width | Cap at a sensible max (e.g. `maxWidth: 400` or similar) if the container width exceeds a comfortable line length for the lockup's 3.08:1 aspect ratio on tablet-width simulators | Prevents an oversized/blurry-looking lockup on wider screens; exact value at implementer's discretion per CONTEXT.md "Claude's Discretion" |
| Loading/error state for the `Image` | None required — this is a bundled local asset (`require(...)`), not a remote image; no loading spinner or fallback needed | Matches how every other bundled asset (icon, splash) is referenced in this codebase — no network involved |
