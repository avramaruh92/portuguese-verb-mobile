## Color

Full palette rewrite — replaces the entire current `colors` export in `src/theme/tokens.ts` (locked by CONTEXT.md D-01/D-02). Rename in place, no dead/duplicate keys, no additive legacy aliases.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `background: #FFFFFF` | Screen backgrounds (unchanged from current) |
| Secondary (30%) | `surface: #F2F2F1` | NEW neutral-gray token — `ReportFeedbackModal` input field backgrounds, reason-picker buttons (default/unselected state), and any other current `colors.secondary` gray usage EXCEPT `OfflinePill` |
| Accent (10%) | `primary: #E8663D` | Buttons (Start Quiz, Next, Try Again, Submit feedback), active/selected states, links — renamed from `accent`. Reserved list below is authoritative. |
| Accent tint | `primarySoft: #FCE4DA` | Reserved ONLY for `OfflinePill` background (D-03) — do not reuse elsewhere even though it is visually similar to a lighter accent |
| Success | `success: #2FA84F` | Correct-answer choice background (`app/quiz.tsx` `choiceCorrect`), feedback-modal success text |
| Destructive | `error: #D64545` | Wrong-answer choice background (`app/quiz.tsx` `choiceWrong`), feedback-modal error text and retry button, results-screen error text |
| Text primary | `text: #1C1B1A` | Body/heading text — renamed from pure `#000000` |
| Text secondary | `textSecondary: #6B6560` | Captions, helper text — renamed from `#8E8E93` |

Accent (`primary`) reserved for: Start Quiz button (`app/index.tsx`), Next/answer-progression button (`app/quiz.tsx`), Try Again / Share Score primary actions (`app/results.tsx`), selected reason-picker option and Submit-feedback button (`ReportFeedbackModal.tsx`), `OfflinePill` text color. Never used as a body-text color or a default/unselected surface fill.

`primarySoft` reserved for: `OfflinePill` background only (BRAND-04, D-03). Do not let this tint leak into `ReportFeedbackModal`'s neutral surfaces — those migrate to `surface`, not `primarySoft` (this is the exact mistake D-03 calls out to avoid).

Token rename map (old → new, every call site in `app/index.tsx`, `app/quiz.tsx`, `app/results.tsx`, `src/components/OfflinePill.tsx` must be updated, and `ReportFeedbackModal.tsx`'s hardcoded hex must be replaced entirely):

| `colors.error` (`#FF3B30`) | `colors.error` (`#D64545`) | Same key, new value |

## Component-Level Application

### Answer-choice states (`app/quiz.tsx`) — BRAND-03, D-10
Selection *behavior* is unchanged (do not touch `choiceStyle()` logic). Only the color values referenced by the existing style objects change:
- `choiceDefault` background: `colors.surface` (was `colors.secondary`)
- `choiceCorrect` background: `colors.success` (new value `#2FA84F`)
- `choiceWrong` background: `colors.error` (new value `#D64545`)
- `choiceTextDefault` color: `colors.text`
- `choiceTextOnColor` color: `colors.background` (`#FFFFFF`, white) — this is correct as-is since `colors.background` is white; do not introduce a separate "white" literal
- No new interaction states, no animation, no haptics — out of scope (matches `UI-04` deferred item)

### `OfflinePill` (`src/components/OfflinePill.tsx`) — BRAND-04, D-03, D-04
- `container.backgroundColor`: `colors.primarySoft`
- `container.borderRadius`: `radius.pill` (999)
- `text.color`: `colors.primary`
- Copy stays exactly `"Using saved content"` (`OFFLINE_PILL_TEXT` constant unchanged)
- Padding stays `spacing.sm` horizontal, `spacing.sm / 2` vertical, `spacing.md` bottom margin (D-06 — unchanged)

### `ReportFeedbackModal.tsx` — BRAND-02
Full migration from hardcoded hex to tokens per the map above. No visual redesign beyond color/token substitution — same layout, same component structure, same states (`idle`/`submitting`/`success`/`error`). Neutral surfaces (reason-option default bg, text-input bg) use `colors.surface`, NOT `colors.primarySoft` (D-03 explicit warning against accidental coral tint spreading to neutral UI).

### Setup, Quiz, Results screens (`app/index.tsx`, `app/quiz.tsx`, `app/results.tsx`) — BRAND-02
Apply the token rename map above to every `colors.accent`/`colors.secondary` call site. No structural/layout changes — this phase is a token-value and token-name substitution only.

### `textOnSurface` — Claude's Discretion, resolved
No dedicated `textOnSurface` token is introduced. `colors.surface` (`#F2F2F1`, a light neutral gray) uses the existing `colors.text` (`#1C1B1A`) for primary text and `colors.textSecondary` (`#6B6560`) for secondary/placeholder text on top of it — both pass basic contrast against `#F2F2F1` and match CONTEXT.md's explicit instruction to default to reusing existing text colors unless implementation reveals a contrast problem.
