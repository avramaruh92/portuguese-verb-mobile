and produce a concrete discrepancy list for the user to spot-check before
sign-off (D-01). This is the autonomous half of Phase 6 Success Criterion 1;

patterns it may repeat when just re-reading.

— a findings list (possibly empty). NO edits to `verbs.ts` in this plan.

<interfaces>
From src/dataset/types.ts — the exact key sets every conjugation table uses:
- TENSES: present_indicative | preterite | imperfect | future
- SUBJECTS: eu | tu | ele_ela | nos | voces | eles_elas
- Verb shape: { verb, translation, isIrregular, conjugations: Record<Tense, Record<Subject, string>> }

Subject-to-person mapping for European Portuguese conjugation:
- eu = 1st singular, tu = 2nd singular, ele_ela = 3rd singular,
  nos = 1st plural, voces = 3rd plural (treated as você-group),
  eles_elas = 3rd plural
NOTE: voces and eles_elas both take the 3rd-person-plural verb form in
European Portuguese — identical strings for these two keys is EXPECTED and
NOT a discrepancy.
</interfaces>
</context>

    conjugation strings (4 tenses × 6 subjects) from European Portuguese

    WITHOUT copying the existing cell first — derive, then compare to the value
    in verbs.ts. Apply the standard EP regular endings for present_indicative,
    preterite (pretérito perfeito), imperfect (pretérito imperfeito), and
    future (futuro do indicativo). Treat identical voces/eles_elas strings as

    disagrees with verbs.ts, record a discrepancy row. Do NOT edit verbs.ts —
    corrections are applied in Plan 02 only after user sign-off. Create the
    findings file with a top-level heading, a "## Regular verbs" section
    containing a markdown table with columns: verb | tense | subject | current
    value | suspected correct value | confidence | note. If a regular verb has
    zero discrepancies, do not list its cells; instead note it as clean in a
    running "verbs checked, no discrepancies" list so coverage is auditable.
    Include every regular verb in either the discrepancy table or the clean
    list — completeness of coverage is the deliverable, per D-01.
  </action>
