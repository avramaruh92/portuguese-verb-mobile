Screens (Expo Router): `app/index.tsx` = Setup (tense selection + verb mode), `app/quiz.tsx` =
one question at a time with locked-choice feedback and an explanation panel, `app/results.tsx` =

correct/incorrect state — this is the state D-11 wants in shot 2 (the Phase 33 press-state color
fix is what made this state correct).

Native project: an `ios/` directory is checked in, so `npx expo run:ios` performs a real native
build rather than running through Expo Go.

Required bucket: 6.9-inch iPhone, portrait, 1320 x 2868 pixels. An iPhone 16 Pro Max simulator
captures at exactly that resolution with no post-processing.

Capture command (RESEARCH.md Code Examples): `xcrun simctl io booted screenshot <path>.png`
Verification command available on macOS: `sips -g pixelWidth -g pixelHeight -g hasAlpha <path>`
`sharp` is already a devDependency (used by `scripts/validate-brand.ts`) and its `removeAlpha()`
is available if a capture comes out with an alpha channel.
