```typescript
export function selectExplanation(
  verb: Verb,
  selectedAnswer: string,
  correctAnswer: { tense: Tense; subject: Subject },
  learning: LearningContent | undefined,
): string | undefined;
```
NOTE: the 3rd param is a { tense; subject } OBJECT, not a string. Pass
`question` itself — `Question extends Triple` already has tense/subject.

```typescript
interface Question extends Triple { choices: string[]; correctAnswer: string; }
// Triple has: verb, tense, subject
```

quiz.tsx already has: `question`, `lockedChoice`, `currentVerb` (now formIndex-bearing).
