<objective>
Upgrade `selectExplanation` (`src/learning/explain.ts`) to match the backend v0.4
explanation template contract: resolve and interpolate the selected (wrong) answer's
tense/subject labels (`selectedTenseLabel`, `selectedSubjectLabel`) alongside the
existing correct-answer labels, and append backend-authored `tenseNotes[correctTense]`
/ `subjectHints[correctSubject]` to the returned text when present. All new behavior
stays fail-closed exactly as in v0.3 — no fabricated grammar text and no new throw
path when `learning`, `formIndex`, the verb entry, or a selected-answer match is
missing.

Purpose: Consume the backend v0.4 content contract (proven to parse in Phase 17)
so learners see richer, backend-authored explanation text without the app ever
authoring grammar wording itself.
Output: Extended `src/learning/explain.ts` and extended
`__tests__/learning-explain.test.ts`. No new files, no schema changes, no UI changes.
</objective>
