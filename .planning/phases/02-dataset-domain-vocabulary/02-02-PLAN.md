Selection rules (from CONTEXT.md, non-negotiable):
- D-01: ~35-40 regular verbs + ~10-15 of the most common irregulars. Total target 50.
  Named core irregulars: ser, estar, ter, ir, fazer, poder, querer, dizer, ver, dar,
  vir, saber, pôr.
- D-02: among regulars, target skew ~50% -ar, ~30% -er, ~20% -ir; all three classes
  must appear so every conjugation pattern gets quiz coverage.
- D-05: `isIrregular: true` iff the verb deviates from the regular -ar/-er/-ir pattern
  in the PRESENT INDICATIVE specifically. A verb regular in the present but irregular
  in a later tense stays `isIrregular: false`.

Authoring constraint (RESEARCH Pitfall 2): every verb is a flat object literal typed
as `Verb`. No spread/merge/programmatic generation.
</context>
