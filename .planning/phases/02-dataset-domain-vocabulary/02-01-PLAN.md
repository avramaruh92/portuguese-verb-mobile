  <action>
    In `src/dataset/types.ts` declare and export: literal union `Tense = "present_indicative" | "preterite" | "imperfect" | "future"`; literal union `Subject = "eu" | "tu" | "ele_ela" | "nos" | "voces" | "eles_elas"` (exact strings per D-03 / CLAUDE.md — no other spellings, no display labels here, those are deferred to Phase 4 per D-03); `readonly` const arrays `TENSES` and `SUBJECTS` holding those literals in the exact order shown (typed `readonly Tense[]` / `readonly Subject[]`); and `interface Verb { verb: string; translation: string; isIrregular: boolean; conjugations: Record<Tense, Record<Subject, string>> }`.     In `src/dataset/validate.ts` import `z` from `zod` and build the schema as fully-spelled-out `z.object()` shapes (RESEARCH Pattern 1): `SubjectConjugationsSchema` = `z.object` with the six explicit keys `eu, tu, ele_ela, nos, voces, eles_elas` each `z.string().min(1)`; `TenseConjugationsSchema` = `z.object` with the four explicit keys `present_indicative, preterite, imperfect, future` each set to `SubjectConjugationsSchema`; `VerbSchema` = `z.object` with `verb: z.string().min(1)`, `translation: z.string().min(1)`, `isIrregular: z.boolean()`, `conjugations: TenseConjugationsSchema`. Export `VerbSchema`. Export `validateDataset(verbs: unknown[]): { valid: boolean; errors: string[] }` that iterates the input, calls `VerbSchema.safeParse()` per element (never `.parse()`, never throws), and accumulates one human-readable error string per failing verb that includes the index and the failing `issue.path` (e.g., `conjugations.future.eles_elas`), returning `{ valid: errors.length === 0, errors }`. Do NOT use `z.record(SubjectEnum, ...)` or `z.record(TenseEnum, ...)` for `conjugations` — Zod 4's enum-keyed `z.record` can silently pass an incomplete grid (RESEARCH Pitfall 1); the exhaustive `z.object` form is the only acceptable shape.
