<objective>
Replace the `GenerateOptions.includeIrregular: boolean` contract with `verbMode: VerbMode`
(`"regular_only" | "mixed" | "irregular_only"`), convert the quiz engine's eligibility
filter to a 3-way pool filter, update the insufficient-verbs message copy to stop
referencing a removed control, and cover all three modes with unit tests including the
irregular-only insufficient-pool path.

Purpose: MODE-02 (per-mode pool filtering) and MODE-03 (insufficient-pool error still
triggers with corrected copy) are the behavioral core of Phase 13. TEST-03 requires unit
coverage of all three modes plus the existing 10-question/no-duplicate guarantees. This
plan defines the `VerbMode` contract that Plan 02's Setup UI consumes.
Output: Updated types, engine filter, store message, and passing tests.
</objective>
