<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Pressable onPress (UI events) | Answer-choice tap crosses from gesture event into store action |
| Share.share() native call | In-app string sent to iOS share sheet (no network call by Share.share itself — it opens a system UI) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-03 | Tampering | Answer choice `onPress` calling `selectAnswer` | mitigate | Store's `selectAnswer` is a no-op after first lock per D-06; rapid/double taps and multi-finger gestures are safed by the store-level guard, not by UI debouncing |
| T-04-04 | Denial of Service | `Share.share()` rejection | mitigate | Share call is wrapped in try/catch that silently swallows errors — results screen remains interactive regardless of share outcome |
| T-04-05 | Information Disclosure | Error message display | mitigate | D-04 error message is a fixed string in the store, not derived from error object internals — no leak path |
| T-04-06 | Spoofing | Direct navigation to /quiz without session | accept | Guard clause returns null — no crash, no corrupt state. Deep-link navigation to /quiz without a session has no meaningful attack path in a single-user local app with no auth. |
| T-04-SC | Tampering | npm installs | accept | No new packages installed in this plan |
</threat_model>
