<objective>
Build the app's first (and only) outbound network call: `submitFeedback(payload)`, which POSTs the feedback payload to the live backend, enforces a ~90s client-side timeout via manual `setTimeout` + `AbortController`, and collapses every outcome into a `SubmitResult` discriminated union (201→success, 400→validation-error, other→server-error, reject/timeout→network-error).

Purpose: FDBK-02 — the app must handle the backend's real-world success/error/cold-start behavior gracefully. This module is deliberately RN/Zustand-free (only `fetch` + `AbortController`, both global) so it is unit-testable with mocked `fetch` and Jest fake timers, and so it can never couple the quiz lifecycle to network state (FDBK-03 defense).

Output: `src/feedback/submit.ts` + green `__tests__/feedback-submit.test.ts` covering all four branches including the fake-timer timeout case.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Mobile client → external API (HTTPS) | The single outbound crossing: `POST /feedback` to `portuguese-verb-api.onrender.com`. Untrusted response returns here. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-02 | Information Disclosure | 500 / non-201 response handling | mitigate | `submitFeedback` never parses or surfaces the response body on non-201 (collapses to `server-error`/`validation-error` with no payload). Backend already returns only `{error:"InternalServerError"}` on 500, but the client shows generic copy regardless — defense in depth (D-07). |
| T-05-03 | Denial of Service | Hung cold-start request blocking the UI thread | mitigate | Manual 90s `setTimeout` + `controller.abort()` bounds the wait; caller (Plan 03) runs it in modal-local async state so a slow response never blocks the quiz (FDBK-03). Abort treated as "stop waiting," not "guaranteed cancel" (Pitfall 2). |
| T-05-V6 | Cryptography | Transport confidentiality | accept | Plain HTTPS `fetch`; TLS terminated by Render. No client-side crypto, no secrets/API keys in this repo (locked constraint). |
| T-05-SC | Tampering | npm installs | accept | No new packages — `fetch`/`AbortController` are RN globals, zero install. |
</threat_model>
