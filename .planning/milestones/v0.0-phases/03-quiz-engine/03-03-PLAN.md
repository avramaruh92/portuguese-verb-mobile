  <behavior>
    Given a hand-built QuizSession fixture with known correctAnswers and a parallel answers array:
    - all correct: answers exactly equal each question's correctAnswer → `{ correct: N, total: N }`.
    - all wrong: every answer differs → `{ correct: 0, total: N }`.
    - mixed: a known subset matches → correct equals that subset's size; total equals questions.length.
    - null answer: an unanswered slot (null) counts as incorrect, not a crash.
    - total reflects session length: total always equals `session.questions.length` regardless of the answers array.
  </behavior>
