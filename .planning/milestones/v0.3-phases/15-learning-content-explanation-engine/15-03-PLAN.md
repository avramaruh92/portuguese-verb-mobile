<objective>
Implement the pure explanation-selection function `selectExplanation` in a new
`src/learning/explain.ts` — the core deliverable of Phase 15. Given a verb, a
selected (wrong) answer string, the correct answer's `{tense, subject}` slot,
and the parsed learning content, it resolves the selected answer's actual slot
via `formIndex`, classifies the mismatch, picks the matching backend template,
interpolates it, and returns the string — or `undefined` when no confident
match exists.

Purpose: TEST-05 — unit-tested explanation-selection with correct template per
mismatch type, missing-content fallback (no throw, `undefined`), and a proof
that generation never mutates scoring/feedback data.
Output: `src/learning/explain.ts`, `__tests__/learning-explain.test.ts`.

This plan is TDD: write the failing test file first (RED), then implement to
green (GREEN). No UI — the returned string is consumed by Phase 16.
</objective>
