<objective>
Close the two wiring gaps that today prevent the Quiz screen from ever
resolving a formIndex-bearing Verb or the LearningContent block for the
current session. This plan makes the data available; Plan 02 renders it.

Gap 1: `useQuizStore.startQuiz` destructures only `{ verbs }` from
`resolveVerbs()` and discards `learning` — nothing exposes `learning` to
screens. Gap 2: `app/quiz.tsx` imports the bundled local `src/dataset/verbs.ts`
array and does `verbs.find(...)` against it, so `currentVerb` never has
`formIndex` even on a successful remote fetch.

Purpose: Without these fixes, `selectExplanation` (Plan 02) can never receive
the inputs it needs, and the panel would silently never appear. Both are
additive, non-breaking state extensions per RESEARCH.md Option A.
Output: An extended store carrying `verbs`/`learning` snapshots and a Quiz
screen that reads its verb list from that snapshot.
</objective>
