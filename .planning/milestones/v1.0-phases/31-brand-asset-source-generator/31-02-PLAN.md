<objective>
Rewrite `scripts/generate-brand-assets.ts` to extract mark layers by stable id instead of counting
`fill="#F2643E"` string occurrences, compose different layer subsets per output variant, compute the
safe-zone bbox per variant, and regenerate all five PNG outputs from the promoted source.

Purpose: The fill-count check was the brittleness this phase exists to remove (D-02). Anchoring
extraction to ids also makes the three-layer Warm Bold Mark expressible per-output, which the
depth-layer rules (D-06 colour outputs keep it, D-07 monochrome drops it) require.

Output: A rewritten generator and five regenerated PNGs.
</objective>

```typescript
type MarkLayerId = "mark-depth" | "mark-fill" | "mark-highlight";

interface ExtractedMark {
  /** transform attribute of the unnamed <g> that parents all three layers,
   *  i.e. "translate(512 512) scale(0.96) translate(-512 -512)" */
  groupTransform: string;
  /** serialized outerHTML of each ided layer element, keyed by id */
  layers: Record<MarkLayerId, string>;
}

function extractMarkOnly(svg: string): ExtractedMark;

/** Re-wraps the requested layers in the parent group so the 0.96 scale is preserved. */
function composeMark(mark: ExtractedMark, ids: readonly MarkLayerId[]): string;

// Unchanged signatures — they consume whatever markup string they are handed:
function wrapMarkDoc(markMarkup: string, viewBox: string): string;
function buildFullIconDoc(markMarkup: string): string;
function getMarkBBox(markOnlyDoc: string): { x: number; y: number; width: number; height: number };
async function renderCenteredOnSafeZone(croppedMarkDoc: string, bbox: { width: number; height: number }): Promise<Buffer>;

// Changed input contract: receives fill+highlight markup only, never depth (D-07).
function toMonochromeSilhouette(markMarkup: string): string;
```

Promoted source structure this parses against (from plan 31-01):

```xml
<svg width="1024" height="1024" viewBox="0 0 1024 1024" fill="none" xmlns="http://www.w3.org/2000/svg">
  <rect width="1024" height="1024" rx="230" fill="#FFF9F6"/>
  <g transform="translate(512 512) scale(0.96) translate(-512 -512)">
    <g id="mark-depth" transform="translate(18 22)" opacity="0.18"><path ... fill="#C94A2D"/></g>
    <path id="mark-fill" fill-rule="evenodd" clip-rule="evenodd" d="..." fill="#F2643E"/>
    <path id="mark-highlight" d="..." fill="#F2643E"/>
  </g>
</svg>
```
