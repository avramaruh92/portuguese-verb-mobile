| Boundary | Description |
|----------|-------------|
| repo `store/` artifacts -> Apple's public listing | Manual transcription can silently diverge from the reviewed source |
| developer answers -> Apple's privacy and age-rating questionnaires | These are legal-weight declarations to Apple and to users |
| submitted version -> public App Store | Once approved, the listing, privacy label, and rating are publicly binding |
