    Create `scripts/generate-brand-assets.ts` (new top-level `scripts/` folder). The script reads
    `assets/brand/lafa-logo-v2.svg` as a UTF-8 string with `readFileSync` and NEVER writes back to
    any path under `assets/brand/` (ICON-04). Follow project conventions: named imports, `import type`
    for type-only imports, external packages first, SCREAMING_SNAKE_CASE for fixed values, and
    fail-loud `throw new Error(...)` on any violated invariant (mirror src/dataset/remote.ts).

    Declare constants: `SOURCE_SVG_PATH = "assets/brand/lafa-logo-v2.svg"`,
    `ICON_OUTPUT_PATH = "assets/images/icon.png"`, `SPLASH_OUTPUT_PATH = "assets/images/splash-icon.png"`,
    `ICON_BACKGROUND = "#FCE4DA"`, `ICON_SIZE_PX = 1024`, `SPLASH_WIDTH_PX = 228`,
    `CROP_VIEWBOX = "192 92 640 640"`.

    Icon variant (ICON-01, per D-01/D-02/D-03):
    - Extract the `<g id="icon">` block by string slicing: `indexOf('<g id="icon">')` to the first
      `indexOf("</g>", groupStart)` plus the length of `</g>`. Throw a descriptive Error if either
      boundary is not found ("source may have changed shape").
    - Wrap the extracted group verbatim in a fresh minimal SVG root whose `viewBox` is `CROP_VIEWBOX`
      and `xmlns="http://www.w3.org/2000/svg"` — this drops the outer white rect and the `<text>`
      wordmark and bleeds the peach rounded-square to the canvas edges.
    - Render with `new Resvg(iconDoc, { fitTo: { mode: "width", value: ICON_SIZE_PX }, background: ICON_BACKGROUND })`.
      The `background: "#FCE4DA"` fills the transparent rounded-corner gaps with the same peach and
      strips alpha (produces a no-alpha PNG matching the mark's own background — no OS-facing rounded
      corners baked in).
    - Before writing, read the render object's `.width`/`.height`; throw if either is not exactly 1024
      (Pitfall 1 — assert square, fail loud). Then `writeFileSync(ICON_OUTPUT_PATH, render.asPng())`.

    Splash variant (ICON-03, per D-06/D-11 — white silhouette, no green dot):
    - Start from the same extracted icon-group markup. Remove the background `<rect x="192" y="92" ...>`
      (first child). Remove the green accent dot entirely — the `<circle cx="667" cy="522" r="18" fill="#2FA84F"/>`
      element is dropped, not recolored (D-11).
    - Recolor to white monochrome: replace `fill="#E8663D"` -> `fill="#FFFFFF"` and
      `stroke="#E8663D"` -> `stroke="#FFFFFF"` (global). Leave the existing `fill="#FFFFFF"` circle-hole
      as-is. Result is a solid white silhouette of the 'a' glyph (the "simple white silhouette" from
      CONTEXT specifics).
    - Wrap in a minimal SVG root with `viewBox = CROP_VIEWBOX`. Render with
      `new Resvg(splashDoc, { fitTo: { mode: "width", value: SPLASH_WIDTH_PX }, background: "rgba(0,0,0,0)" })`
      — TRANSPARENT background (do NOT flatten; the #208AEF plugin blue must show through per D-05).
    - `writeFileSync(SPLASH_OUTPUT_PATH, render.asPng())`.

    The script runs its work at module top level (or a named `main()` invoked at the bottom) so
    `node scripts/generate-brand-assets.ts` executes it directly. If any helper is factored out, use
    named exports (no default exports).
  </action>
