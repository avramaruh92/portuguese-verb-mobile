<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local machine → EAS cloud build service | source archive uploaded; compilation + code signing happen server-side |
| EAS → Apple credential service | distribution certificate / provisioning profile generated and stored remotely (EAS-managed) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-20-02 | Information Disclosure | Apple credentials (.p12 / .mobileprovision / ASC key) accidentally committed | mitigate | Use EAS-managed remote credentials only ("Let EAS manage credentials"); no `credentialsSource: local` in eas.json; verify `git diff eas.json app.json` before committing contains only build-profile config + projectId, zero secret material |
| T-20-03 | Spoofing | Build registered under a placeholder/scratch bundle identifier | mitigate | Task 1 sets the final `com.avram.aruh.lafa` before build:configure so credentials/project are never bound to a throwaway id (D-01) |
| T-20-01 | Tampering | Global eas-cli shadowing pinned version during build/configure | mitigate | All EAS commands run via `npm run eas -- <subcommand>` (inherited from Plan 01) |
</threat_model>
