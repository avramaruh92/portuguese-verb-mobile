<objective>
Remove the `eas-cli` devDependency and the redundant `"eas": "eas"` npm script from
`package.json`, regenerate `package-lock.json` under the pinned Node 22.23.2, and prove the
full local verification suite still passes.

Purpose: `npx expo-doctor` flags both items — the `eas` script conflicts with
`node_modules/.bin/eas`, and EAS CLI is explicitly documented as a tool that should be run
globally or via `npx`, never installed as a project dependency. Both were a deliberate v0.5
Phase 20 tradeoff (D-04) taken because a stale global `eas-cli@20.0.0` shadowed bare
`npx eas-cli` on the dev machine. That condition no longer holds — the machine's global
`eas-cli` is now `21.2.0`, which satisfies `eas.json`'s `cli.version: ">= 21.1.0"`. The
mitigation has outlived its cause, so the local pin can be retired.

Output: A slimmer `package.json`, a regenerated `package-lock.json` with the entire
`eas-cli` dependency tree gone, and a green `npm ci` / typecheck / lint / test run.
</objective>
